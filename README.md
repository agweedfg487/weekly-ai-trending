## 项目详情

### 1. Anthropic Skills

**项目链接：** [anthropics/skills](https://github.com/anthropics/skills)

Anthropic 官方维护的技能库项目，提供一系列可复用的 AI Agent 技能定义。这些技能涵盖代码审查、文档生成、架构设计等开发任务，可直接集成到 Claude Code、Cursor 等 AI 编码助手中。项目强调生产级工程实践，适合希望构建可靠 AI 辅助开发流程的团队使用。

---

### 2. Agent Skills by Addy Osmani

**项目链接：** [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)

Google Chrome 工程师 addyosmani 开源的 AI 编程技能库。内容覆盖需求澄清、Code Review、测试编写、Git 提交等多个阶段，为 Codex、Claude Code 等智能体提供可复用的工程能力模块，帮助团队建立更规范的开发流程。项目强调生产级质量标准和团队协作实践。

---

### 3. Daily Stock Analysis

**项目链接：** [ZhuLinsen/daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)

LLM 驱动的多市场股票智能分析系统。提供多源行情数据、实时新闻追踪、决策看板生成和自动推送功能，支持零成本定时运行。项目集成了多种金融数据 API 和自然语言处理能力，适合量化交易研究和投资决策辅助场景。

---

### 4. Vercel Labs Agent Browser

**项目链接：** [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser)

Vercel Labs 推出的浏览器自动化 CLI 工具，专为 AI Agent 设计。它提供标准化的浏览器交互界面，支持网页导航、元素定位、表单填写等操作，让 AI Agent 能够像人类一样使用浏览器完成任务。适合需要浏览器自动化能力的 AI 应用开发。

---

### 5. Meta Astryx

**项目链接：** [meta/astryx](https://github.com/meta/astryx)

Meta 开源的可定制设计系统，完全适配 AI Agent 工作流。项目提供了一套完整的 UI 组件和设计 token，支持通过自然语言指令动态生成和调整界面布局。适合快速原型开发和 AI 驱动的可视化应用构建。

---

### 6. Claude Quickstarts

**项目链接：** [anthropics/claude-quickstarts](https://github.com/anthropics/claude-quickstarts)

Anthropic 官方提供的 Claude 快速入门项目集合。包含多个实用示例和模板代码，帮助开发者快速上手 Claude API 并构建可部署的应用程序。项目覆盖了不同编程语言和应用场景，是学习 AI 集成的理想起点。

---

### 7. Elephant Goldfish Model

**项目链接：** [google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model)

Google 开源的大模型插件框架，专注于设计和审查软件系统的 Agent 协作。该项目展示了如何通过插件化架构提升大模型在软件工程任务中的推理能力和知识密度，适合对 AI 辅助设计感兴趣的开发者与研究人员参考。

---

### 8. MuJoCo

**项目链接：** [google-deepmind/mujoco](https://github.com/google-deepmind/mujoco)

MuJoCo (Multi-Joint dynamics with Contact) 是 DeepMind 开发的物理仿真引擎，广泛用于强化学习和机器人控制研究。它支持高保真度的物理模拟、接触动力学和复杂机械系统建模，是 AI 研究人员探索智能体学习算法的重要工具平台。

---

### 9. Plan Notator

**项目链接：** [backnotprop/plannotator](https://github.com/backnotprop/plannotator)

计划执行跟踪和可视化工具，帮助团队管理软件开发任务和迭代进度。项目集成了 GitHub Issues、PR 管理和里程碑追踪功能，适合敏捷开发团队的日常规划和协作需求。提供清晰的进展视图和自动化状态更新。

---

### 10. OpenMAICBot

**项目链接：** [milind-soni/OpenMAICBot](https://github.com/milind-soni/OpenMAICBot)

OpenMAICBot 是一个面向教育和研究的 AI 对话机器人框架。项目目前处于早期开发阶段，公开仓库中尚未提供详细的描述文档。预计将支持多轮对话、知识检索和个性化回复等功能，可用于构建智能客服、虚拟助手和教育辅导系统。
